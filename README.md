# Drop Of Hope (D.O.H.) website

Static site for the Drop Of Hope smart water management project (Xylem Global Student Innovation Challenge, Water Quantity, High School Track).

## Run
Open `index.html` in a browser (internet needed for Three.js, GSAP and Google Fonts from CDNs). Or serve the folder: `python3 -m http.server`

## Structure
- `index.html` page markup
- `css/style.css` all styles
- `js/main.js` content, navigation, leak simulator, phone mockup, scroll animations
- `js/scene.js` Three.js 3D droplet scene
- `js/effects.js` click splash and living water surface
- `assets/` logo (transparent), optimized team photos, `originals/` untouched uploads

## Edit
Team members: `TEAM` array in `js/main.js`. Hardware cards: `HW`. App screens: `SC`.
